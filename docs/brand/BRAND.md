# switchroom.ai — brand guidelines

> **In-repo mirror.** This directory is the in-repo copy of the switchroom-web
> brand kit (`switchroom-web/public/brand/` + `docs/BRAND.md`). The assets sit
> right beside this file, so links below resolve locally. The canonical source
> is switchroom-web; assets are also served at `https://switchroom.ai/brand/<file>`.

The mark: a brass patch-bay plate (9-jack grid) with a red patch cable
plugged into the four corner jacks, tracing a sinuous "S". The square icon
with the notched red frame is the **primary mark**.

Canonical source lives in the `switchroom-brand` directory (generated by
`build.py` — never hand-edit SVG outputs). This doc plus the assets beside it
is the in-repo copy for anyone who needs an asset or a rule.

## Typography

- Wordmark: **Fraunces**, wght 560, opsz 20, SOFT 0, WONK 0 — all
  lowercase: `switchroom.ai`. Pre-outlined in the lockup SVGs; no
  live-font dependency.
- The wordmark is always a single color — charcoal on light, bone on
  dark. **The ".ai" takes the same color as "switchroom" — never gold,
  never red.**

## Usage rules

- **The red notched frame appears only on the full-color standalone icon
  at ≥64px.** Lockups, sizes below 64px, avatars, and circular crops use
  the frameless plate.
- **Never use the frame in circular contexts** (Telegram, X, maskable
  Android icons). Use `logo-avatar.*` — it keeps everything meaningful
  inside the inner 80% safe circle.
- **Mono marks:** charcoal ink on light backgrounds, bone ink on dark.
  Never a mono-red mark — only the cord is red, and only in full color.
- On dark backgrounds the frame lightens (see `logo-icon-ondark.svg`);
  don't place the light-background icon on charcoal.

## Clear space

Keep **¼ of the icon height** clear on all sides of any mark or lockup.

## Lockup proportions (for reference)

- Horizontal: plate height = icon unit; gap = 0.375× icon width;
  wordmark x-height optically centered on the plate midline.
- Stacked: wordmark width = 1.12× icon width; gap from icon bottom to
  ascender line = 0.5× ascender height.
