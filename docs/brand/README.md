# Design assets

Index to the switchroom design-asset layout under `docs/`:

- **`docs/brand/`** — the official brand kit (logos, icons, favicons, social
  images, `switchroom-brand-pack.zip`) plus the brand guidelines in
  [`BRAND.md`](./BRAND.md). In-repo mirror of the switchroom-web brand kit;
  canonical source is switchroom-web, also served at `https://switchroom.ai/brand/`.
- **`docs/diagrams/`** — the explanatory diagram system (architecture and flow
  diagrams with source specs). See its [`DESIGN.md`](../diagrams/DESIGN.md).
- **`docs/screenshots/`** — staged product screenshots (fictional/staged
  content only, per house rule). See its [`README.md`](../screenshots/README.md).

`docs/assets/` is a separate legacy asset holder and is not part of this
design-asset system.
